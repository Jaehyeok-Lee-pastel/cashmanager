## 🗺️ 여정 타임라인

### 1. 아이디어 & 시장 검증
- **제품 정의**: 뱅크샐러드/토스의 자동연동과 정면승부하지 않고 "수동인데 안 아픈 입력"으로 우회. 핵심 무기 = **AI 입력 마찰 0**.
- **데이터 모델**: `transactions` 단일 ledger + `source` enum + `amount_minor`(KRW 정수) + `merchant_category_map` 학습 루프.
- **NL 파이프라인**: 정규식 선처리 → fast-path 또는 LLM 1회(Structured Outputs strict) → 미저장 미리보기 → confirm. 실패는 `needs_manual` 폴백.

### 2. 보안 우선
- 전 테이블 RLS(`user_id = auth.uid()`) + service 레이어 소유권 재검증 + `enforce_category_owner` 트리거.
- 프롬프트 인젝션 방어: 데이터(system)와 질문(user turn) **구조적 분리**. LLM 실패 시 고정 폴백.
- 비용통제: OpenAI 결제 상한 + rate-limit + 코치 LLM 캐시(재과금 방지).

### 3. 차기 기능 발굴 (수치 기반 의사결정)
- 다관점 워크플로로 후보 채점 → **F1 월 예산** 만장일치 1위(40/50).
- **F1 월 예산**: 카테고리별 한도 + 직전 3개월 평균 자동제안 + 진행바 임계색·초과 배지.
- **F2 AI 자연어 질의 + F3 인사이트/경고**: "분석" 탭. 요약+예산 컨텍스트 → LLM 한국어 답변, 규칙기반 경고.
- **F4~F6 forward-looking**: 월말 지출 페이스 예측 · 달력 뷰 · Safe-to-Spend("오늘 쓸 수 있어요").

### 4. 회계 정확성 — 도메인 난제 해결
- **콜드스타트 예산**: 신규 사용자용 소득 기반 초안(통계청 비율). 이후 **엥겔 보정**으로 발전(투자 많을수록 필수재↑·재량재↓).
- **신용카드 = 이체**: 결제시점=지출, 월 카드대금=이체(이중계산 방지). YNAB·Monarch·뱅크샐러드 근거.
- **첫 달 예외**: 가입 첫 달 카드값은 개별기록이 없으니 '지출'로 — 인앱 안내.

### 5. 입력 견고성
- **오타 결정론 계층**: `hangul.py`(NFC + 자모 오토마타, "기ㅁ밥"→김밥) + 금액단위 오타 변이표("3처넌"→3000).
- **기록 표준화**: 브랜드 별칭맵(맥날→맥도날드 ~35) → merchant_map 키 수렴(학습적중↑·LLM↓).
- **엣지 보정**: "5만 1천원"→51000(공백단위 병합), "내일모레/글피", "다음주 X요일", 소수점 금액 floor.

### 6. 페르소나 검증 & 제품 방향
- 10개 직업군(3명 극비판) 100점 채점 → 평균 65, "개인용임을 명확히" 후 재테스트 78.
- `PRODUCT_DIRECTION.md`: 타깃·핵심가치(입력마찰0 + forward-looking 통제감)·비범위(은행연동·자산설계·가족공유) 확정.

### 7. 성숙도 감사 → A− 5배치
- **검증자산 코드화**: throwaway QA를 영구 pytest로 → 122 → 549 테스트 + vitest + GitHub Actions CI 머지게이트.
- **운영 하드닝**: `/health`(liveness) + `/ready`(DB probe→503), request-id 구조적 로깅.
- **반복/고정지출**: recurring_rules + materialize + Safe-to-Spend 차감.
- **망각 방어선**: 오프라인 입력 큐(localStorage) + 입력 스트릭.

### 8. Dogfooding 피드백 루프 (사용자가 직접 발견)
- **투자 처리**: 주식/펀드/적금 매수=이체(소비 아님). Safe-to-Spend·잔액에서 차감. '투자' 카테고리·목표.
- **잔액 정합**: 수입 − 지출 − 투자 = 실제 남은 현금.
- **급여 사이클 예산(대형)**: 급여일≠1일이면 1일 리셋이 신뢰를 깸 → '급여일 설정'으로 요약 윈도우를 [급여일~다음급여전일]로 이동. 뱅크샐러드식 정공법. 분자·분모 동일 윈도우("싼 패치"는 수학적으로 틀려 회피).
- **분석탭 일관성**: insights/assistant도 같은 급여사이클 → "지난 급여달 대비".
- **투자 분류 정확성**: 적금/펀드 동사가드 + 환매/해지/수수료 제외(잔액 역행 버그 해결).

## 🛠️ 핵심 기술 결정

| 영역 | 결정 | 이유 |
|---|---|---|
| 금액 | `amount_minor` bigint(KRW 정수) | 부동소수 오차 0 |
| 카드/투자 | `direction=transfer`로 분리 | 이중계산 방지, 지출 합계 오염 방지 |
| 급여 사이클 | 분자·분모 동일 윈도우 | 분모만 바꾸는 패치는 수학적으로 틀림 |
| 오타 복원 | 무의존 순수 파이썬 자모 오토마타 | NFC 단독 불가(호환자모 미합성) |
| 예산 비율 | 엥겔 탄력 보간(중앙값=현행) | 데이터 근거 + 회귀 안전 |
| 검증 | throwaway QA → 영구 파라미터 테스트 | dogfooding 발견 버그 회귀 봉인 |
