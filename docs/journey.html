여정 타임라인

01 · 아이디어 & 시장 검증

입력 마찰 0의 가계부

  • 자동연동과 정면승부 대신 "수동인데 안 아픈 입력"으로 우회
  • 단일 ledger + amount_minor(KRW 정수) + 상호→카테고리 학습 루프
  • NL: 정규식 선처리 → fast-path/LLM 1회 → 미저장 미리보기 → confirm
02 · 보안 우선

RLS · 인젝션 방어 · 비용통제

  • 전 테이블 RLS + service 소유권 재검증 + 트리거
  • 프롬프트 인젝션: 데이터(system)와 질문(user) 구조적 분리
  • rate-limit + 코치 LLM 캐시로 재과금 방지
03 · 기능 발굴 (수치 기반)

F1 월예산 · F2 AI질의 · F3 인사이트

  • 워크플로 점수화로 F1 월 예산 만장일치 1위
  • "분석" 탭: 요약·예산 컨텍스트 → LLM 한국어 답변 + 규칙 경고
  • forward-looking 3종: 페이스 예측 · 달력 뷰 · Safe-to-Spend
04 · 회계 정확성

카드 = 이체 · 콜드스타트 · 엥겔 보정

  • 신용카드=이체로 이중계산 방지(YNAB·뱅크샐러드 근거)
  • 콜드스타트 예산 → 투자액 반영 엥겔 탄력 보간(필수재↑·재량재↓)
  • 가입 첫 달 카드값 예외 인앱 안내
05 · 입력 견고성

오타 복원 · 기록 표준화 · 엣지

  • 무의존 자모 오토마타("기ㅁ밥"→김밥) + 금액단위 오타표
  • 브랜드 별칭맵(맥날→맥도날드)으로 학습키 수렴
  • "5만 1천원"→51000, 소수점 floor, "다음주 X요일"
06 · 페르소나 & 방향 확정

10개 직업군 비판 → 65 → 78

  • 3명 극비판 포함 100점 채점 → 개인용 명확화 후 재상승
  • PRODUCT_DIRECTION.md: 타깃·핵심가치·비범위 확정
07 · 성숙도 감사 → A− 5배치

검증자산 코드화 · 운영 하드닝

  • throwaway QA → 영구 pytest 122→549 + CI 머지게이트
  • /health·/ready 분리 · request-id 로깅 · 반복지출 · 오프라인 큐
08 · Dogfooding 피드백 루프

투자 처리 · 급여 사이클 · 분석탭 일관성

  • 투자=이체 + Safe-to-Spend·잔액 차감 + '투자' 목표
  • 급여 사이클 예산: [급여일~다음급여] 윈도우(1일 리셋 제거, 분자·분모 동일 윈도우)
  • 분석탭도 같은 사이클 · 적금/펀드 동사가드(잔액 역행 버그 해결)
