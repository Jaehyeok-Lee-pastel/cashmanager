# 제품 브리프 — AI 입력 가계부 (MVP)

> 확정일: 2026-06-02 · 근거: `budget-app-competitors.md` 경쟁 리서치 + 사용자 결정

## 한 줄 정의
**"입력이 안 귀찮은, 단순하고 똑똑한 개인 가계부"** — 자연어 한 줄로 기록하는 범용 소비자 가계부.

## 확정 결정사항
| 항목 | 결정 | 근거 |
|---|---|---|
| 타깃 | "나 같은 사람" (범용, dogfooding 우선) | 시장 모수 최대 + 본인 실사용 |
| 핵심 무기 | **AI 입력 마찰 0** | 자동연동(MyData) 정면승부 불가 → 수동인데 안 아픈 입력으로 우회 |
| 우회 대상 | 뱅크샐러드·토스 | 무료+자동연동 슈퍼앱. 인디는 MyData 라이선스 불가 |
| 차별 포지션 | 단순·집중 UX + AI 입력 | 자동연동 거부파·수동기록파·슈퍼앱 피로파 공략 |
| MVP 철학 | 기본 가계부 뼈대 + **AI 입력 채널 1개 깊게** | 스코프 절제 |
| AI 입력 1개 | **자연어 한 줄** ("스벅 아메리카노 4900") | 구현 최소(텍스트 LLM)·비용 최저·카드/온라인도 커버 |
| v2 후보 | 영수증 OCR(+품목분리), 음성 입력 | 영수증은 종이 필요·OCR비용, 음성은 STT·공공장소 거북 |

## 핵심 가치 흐름
사용자가 "점심 김밥 4500" 한 줄 입력 → LLM이 `{금액, 카테고리, 메모, 날짜}` 파싱 →
한 탭 확인/보정 → 저장 → 월간 소비 차트/인사이트.

## v2 이후 확장 경로
- 영수증 사진 OCR + **품목 분리(Line-Item Split)** ← 한국 소비자앱 미존재 빈틈 (킬러기능 후보)
- 음성 입력
- 은행 CSV import (MyData 우회 보강 플로우)
- 소비 자각 인사이트(과소비 경고·주간 리포트)
