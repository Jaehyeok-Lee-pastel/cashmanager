# 콜드스타트 예산 비율 — 소비여력 탄력 보정 (엥겔 보정)

## 문제 제기 (사용자)
투자를 많이 해 소비예산이 줄어든 사람과 여유로운 사람에게 **같은 고정비율**을 적용하는 게 맞나?

## 결론: 보완 가치 있음 (작은 보완 — 선형보간 1겹)
4갈래 리서치(엥겔의 법칙·KOSIS 가계동향·50/30/20·YNAB·설계평가)가 한 방향 수렴:
**소비여력↓ → 필수재(식비·생활/마트·의료) 비중↑, 재량재(문화/여가·쇼핑·카페) 먼저 삭감.**

### 근거 (실증)
- 엥겔의 법칙: 소득↓일수록 식비 비중↑ (식료품 소득탄력성 0.3~0.5, 필수재).
- KOSIS 가계동향(2024~2025): 식료품 비중 1분위 **22%** vs 5분위 **12.5%**(격차 ~9%p);
  오락·문화 1분위 **5.3%** vs 5분위 **8.3%**(절대액 6.7만 vs 40.4만, 6배).
- 50/30/20·YNAB: 저축↑ 시 줄이는 건 wants(재량)이지 needs(필수) 아님.

## 채택 모델 — 옵션 d (결정론 선형보간)
- `tightness = clamp((투자/소득 − 0.10) / 0.40, 0, 1)` — 투자 10%↓=여유(0), 50%↑=빠듯(1).
  기본 저축 30% → tightness 0.5 → **현행 비율과 동일(회귀 안전)**.
- 카테고리별 (comfortable, tight) 앵커를 보간 후 합 0.78로 재정규화. **중앙값=현행 비율.**

| 카테고리 | comfortable(여유) | tight(빠듯) | 중앙값(=현행) | 방향 |
|---|---|---|---|---|
| 식비 | 0.20 | 0.28 | 0.24 | 필수↑ |
| 생활/마트 | 0.04 | 0.06 | 0.05 | 필수↑ |
| 건강/의료 | 0.06 | 0.10 | 0.08 | 필수↑ |
| 교통 | 0.13 | 0.11 | 0.12 | 약탄력↓ |
| 카페/간식 | 0.08 | 0.04 | 0.06 | 재량↓ |
| 문화/여가 | 0.11 | 0.05 | 0.08 | 재량↓ |
| 쇼핑 | 0.13 | 0.07 | 0.10 | 재량↓ |
| 기타지출 | 0.05 | 0.05 | 0.05 | 중립 |

주거·통신·카드대금은 제외 유지(편차 최대·사용자 직접입력이 옳음).

## 배제
- 옵션 b(필수재 floor 금액): 1인/지역/연령 편차 커 단일사용자 콜드스타트엔 데이터 부재 → 과적합.
- ML 개인화: 단일사용자 데이터 희소.
