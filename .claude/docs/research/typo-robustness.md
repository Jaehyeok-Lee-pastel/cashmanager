# 오타 감지 + 저장 형식 통일 — 리서치 & 설계

> 산출: Workflow(5 에이전트) — 자모재조합·금액단위오타·LLM정규화·퍼지매칭 4관점 웹리서치 → 아이디어 점수화. 2026-06.
> 사용자 예시: 금액오타 "3처넌"(3천원)·"12마누언"(12만원), 자모깨짐/구어 "기ㅁ밥"(김밥)·"비해ㅇ기"(비행기)·"뱅기"(비행기 구어).

## 핵심 결론
**두 문제(자모 깨짐 vs 금액 단위 오타)를 분리하고, 결정론으로 싸게 잡을 것 / 퍼지 / LLM·학습맵에 위임할 것의 경계를 명확히** 그으면 $5·단일사용자·오프라인 제약을 거의 위반 없이 충족. 결정론이 더 많이 흡수할수록 LLM 호출·비용은 오히려 감소.

**예시 5개 책임분담**: 기ㅁ밥·비해ㅇ기 = 자모 automata 결정론 100% / 3처넌·12마누언 = 금액 노멀라이저 결정론 ~100% / 뱅기(의미축약) = LLM·학습맵(한 번 confirm→영구 수렴).

> ⚠️ NFC 함정: `unicodedata.NFC`는 떠다니는 호환용 자모(ㅁ,ㅇ)를 음절에 **절대 안 붙임**(Unicode 의도적 설계). "기ㅁ밥" NFC만으론 안 고쳐짐 → 별도 자모 오토마타 필수.

## 아이디어 점수 (0~100)
| 점수 | 아이디어 | 계층 | 잡는 것 |
|---|---|---|---|
| **90** | 금액 단위 결정론 노멀라이저 (폐쇄집합 자모 fuzzy) | 결정론 | 3처넌→3천원, 12마누언→12만원 |
| **88** | 자모 automata 복원 (떠다니는 호환자모 흡수) | 결정론 | 기ㅁ밥→김밥, 비해ㅇ기→비행기 |
| **82** | 별칭/구어 사전 + 학습루프 위임 | 저장정규화 | 뱅기→비행기, 맥날→맥도날드 |
| **80** | 상호 자모 Levenshtein 퍼지매칭 (학습맵 exact 실패 시) | 퍼지 | 스벜↔스벅 표기흔들림 |
| **78** | NFC 진입점 통일 (SSOT 전제조건) | 결정론 | (직접 X, 후속단계 안전 보증) |
| **70** | LLM 스키마에 normalized_memo/merchant 2필드 | LLM | 잔여·문맥의존 (추가 호출 0) |
| **38** | symspellpy-ko 범용 교정 (메인채택) | 퍼지 | 대형사전 과적합 → 아이디어만 차용 |

> 배제: py-hanspell(온라인·비공식·상업부적합), Soundex/Metaphone(로마자화 오차).

## 권장 4계층 파이프라인 (nl_service.parse, LLM 전 최대 흡수)
- **L0 NFC 정규화**: parse 최상단 1회. 자모표기 혼재 통일. raw_input은 정규화 '전' 원문 보존.
- **L1 자모 automata 복원**(무비용): merchant_keyword 토큰 한정. 떠다니는 호환자모를 보수규칙(앞 음절 종성 비었음 + 유효 종성 + ㅋㅋ/이모지 아님)으로 흡수. 어휘검증 통과 시만 채택.
- **L1' 금액 단위 노멀라이저**(무비용): `_parse_korean_number` 앞단. [숫자인접][한글덩어리][원동반] 강컨텍스트에서만 {만천백십원} 자모열 가중 edit-distance 스냅. 모호하면 None→LLM. 과교정(만나손칼국수·백다방) 차단.
- **L2 퍼지매칭 fallback**(무비용): merchant_map exact 실패 가지에 RapidFuzz 자모-Levenshtein(score_cutoff 0.85+, 길이<2는 exact만).
- **L3 LLM 보정**(추가호출 0): 기존 1회 호출 스키마에 normalized 2필드. '확실한 오타/구어만 교정, 모르면 원문유지, 유명브랜드 추측 금지'. **금액은 절대 위임 안 함**(결정론 고정).

## 저장 형식 통일
1. `raw_input` = NFC '이전' 원문(롤백·감사). `memo` = NFC만 적용(교정 X, 표시·검색 안정).
2. 정규화 함수 SSOT 단일화(`normalize_merchant`/`normalize_amount_run`) — 결정론·LLM 경로 공유로 학습맵 키 분열 방지.
3. `merchant_category_map` 키 = 표준 상호로 upsert(스벅/스타벅스/스벜 → 한 키 수렴, 희소성 완화). 별칭은 동일 category_id 추가 엔트리.
4. `amount_minor`는 이미 KRW 정수. `parse_meta.corrected_from='3처넌'` 근거 남겨 롤백.

## 핵심 가드 (2개)
- **과교정 방지**: 단위 복원은 강컨텍스트일 때만 발동, 모호하면 None→LLM. 퍼지 임계 보수적. 변이표 강유닛테스트.
- **원문 불변**: raw_input 비가공 보존, 정규화는 amount_minor·category 산출에만, corrected_from 기록.

## 로드맵 (저공수·고ROI 순)
1. **금액 단위 노멀라이저**(90) — 즉시. 핵심 타깃을 가장 싸게.
2. **자모 automata 복원**(88) — 기ㅁ밥·비해ㅇ기.
3. **NFC SSOT 통일**(78) — 1·2 동시 전제.
4. **퍼지매칭 fallback**(80) — 표기흔들림.
5. **LLM normalized 2필드 + 별칭/학습루프**(70/82) — 과교정 방어가 핵심이라 결정론 안정화 뒤.
- 보류: symspellpy-ko 메인채택(대형사전 과적합).
