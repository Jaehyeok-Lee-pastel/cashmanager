# 캐시매니저 고도화 후보 — 리서치 & 다관점 ROI 점수화

> 산출: Workflow(35 에이전트) — 5관점 웹리서치(한국앱·글로벌앱·AI트렌드·간단ML·갭) → 14후보 도출 → 후보별 가치/회의 2관점 독립 채점 → 종합. 2026-06.
> 가중치: ROI 0.25 · 실용성 0.25 · 구현용이 0.15 · 차별화 0.15 · 비용적합 0.10 · 데이터충분성 0.10.

## 핵심 결론
단일 사용자·데이터 희소·$5 상한 제약에서 **ML류는 구조적으로 ROI가 낮다**(학습/유의성 데이터 부재). 가장 큰 체감 가치는 **이미 가진 자산(예산·요약·인사이트)을 forward-looking으로 묶는 산술 기능**에 있다. → 예산을 "사후 집계"에서 "사전 경고 + 오늘 한도 + 한눈 그림"으로 격상.

## 티어
- **Tier 1 (지금 하라)**: 1·2·3위 — 비용 0, 데이터 적합성 만점, 구현 수십~수백 줄. forward-looking 예산 3종 세트.
- **Tier 2 (검토 후 택1)**: 재정메모리·순자산스냅샷·리밸런싱카드·목표저축·무지출스트릭 — 가치 중간, 1인 사용 동기훅이 변수. 가볍게 만들어 dogfooding 검증.
- **Tier 3 (보류)**: 고정지출탐지·주간리캡·현금흐름예측·이상탐지·룰승격ML·NL검색 — 데이터 희소로 실효 낮거나 기존 기능과 중복.

## 솔직히 권하지 않음 (데이터 부족 ML)
1. **룰빌더+ML 승격(50)**: 핵심가치(룰승격→LLM생략)는 이미 라이브 merchant_map 학습루프가 N=1에서 달성 중 → 중복. ML 승격은 단일 사용자라 트리거 표본 부재 → 죽은 코드.
2. **고정지출 자동탐지(61, 데이터3.5)**: 월1회·단일사용자라 통계 유의까지 2~3개월+. 콜드스타트가 본질 약점.
3. **현금흐름 예측(57, 데이터4)**: 반복탐지·잔액 기준점 둘 다 미존재. sparse 데이터에서 낙관 편향.
4. **이상탐지(56)**: 본인이 입력한 데이터라 '이상'이 정보 서프라이즈를 못 줌. 오탐·부정적 네이밍 리스크.
5. **NL 검색(49)**: 기존 칩/날짜 필터·NL assistant와 중복.

> 공통: 이 제약(단일사용자·희소데이터·$5)에서 'ML/패턴 자동탐지'는 데이터 자체가 없어 ROI가 구조적으로 낮다. 다중 사용자화 또는 수개월 누적 시 재평가.

## 권장 로드맵
- **스프린트1** — 월말 페이스 예측(1위). **경과일 임계(월초 거짓경고 차단) + 일회성 이상치 보정** 필수. `/startproject` 설계리뷰 후 구현.
- **스프린트2** — 달력 뷰. 순수 프론트, 백엔드 무변경. 1과 병렬/직후.
- **스프린트3** — Safe-to-Spend '오늘 일 한도' 단일 숫자(recurring 차감 항 제외, 좁게).
- **스프린트4+** — Tier2에서 dogfooding 신호 보고 택1.
- **보류 재평가 트리거**: 데이터 수개월 누적 또는 사용자 증가 시.
